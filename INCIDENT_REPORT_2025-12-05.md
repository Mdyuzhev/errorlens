## 4. Корневая причина (Root Cause)

### Основная проблема: Дублирование экземпляров бота

На сервере одновременно работали **два экземпляра** Telegram-бота EL_Bot:
1. **Docker-контейнер** `el-bot` — запущен напрямую через `docker run`
2. **K8s Pod** `el-bot-xxx` — запущен через K8s Deployment в namespace `bots`

Оба экземпляра использовали **один и тот же Telegram Bot Token**, что вызывало:
- Ошибку `Conflict: terminated by other getUpdates request`
- Бесконечные перезапуски и race conditions
- Повышенное потребление ресурсов

### Механизм падения

```
el-bot (Docker) ──┐
                  ├── Telegram API ── "Conflict: terminated by other..."
el-bot (K8s)   ──┘
                  │
                  ▼
        Бесконечные retry → OOM/CPU spike → SIGTERM → SIGKILL
```

Журнал Docker (`docker inspect --format='{{.State.ExitCode}}' <container>`):
- Exit Code: 137 (128 + 9 = SIGKILL)
- OOMKilled: false
