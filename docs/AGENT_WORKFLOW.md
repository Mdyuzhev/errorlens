# Как работать с Claude Code агентом

> 📋 Это руководство объясняет как эффективно использовать Claude Code в VS Code для работы над ErrorLens

---

## Структура контекста

```
errorlens/
├── CLAUDE.md                    # 🔴 ГЛАВНЫЙ контекст (читается автоматически!)
├── .claude/
│   └── settings.local.json      # Настройки и preferences
└── docs/
    ├── TECHNICAL_AUDIT_*.md     # Текущий статус проекта
    └── instructions/
        ├── WAVE_3.2_PHASE_1_BOOKMARKLET.md
        ├── WAVE_3.2_PHASE_2_BACKEND.md
        ├── WAVE_3.2_PHASE_3_FRONTEND.md
        └── WAVE_3.2_PHASE_4_TESTS.md
```

---

## Как Claude Code получает контекст

| Источник | Когда читается | Приоритет |
|----------|----------------|-----------|
| `CLAUDE.md` | **Автоматически** при старте | 🔴 Высший |
| `.claude/settings.local.json` | Автоматически | Высокий |
| Открытые табы в VS Code | Всегда доступны | Средний |
| Файлы через `@file` в чате | По запросу | Средний |
| Файлы через Read tool | По необходимости | Низкий |

## Как начать работу

### Вариант 1: Новая сессия, продолжение работы

Просто открой проект и напиши в чат:

```
Продолжаем WAVE 3.2. Какая фаза сейчас актуальна?
```

Агент прочитает `CLAUDE.md` автоматически и предложит следующие шаги.

### Вариант 2: Конкретная задача

Укажи конкретный файл инструкций:

```
@docs/instructions/WAVE_3.2_PHASE_1_BOOKMARKLET.md

Выполни задачу 1.1 - настрой esbuild
```

### Вариант 3: Быстрый контекст

Если нужно напомнить агенту о проекте:

```
Прочитай CLAUDE.md и docs/TECHNICAL_AUDIT_2025-12-05.md, затем предложи следующие шаги
```

---

## Правила для агента

Эти правила прописаны в `CLAUDE.md` и `settings.local.json`:

1. **Читай CLAUDE.md** в начале каждой сессии
2. **Router → Service → Repository → Model** — не обходить!
3. **Файлы ≤500 LOC**
4. **Type hints везде** в Python
5. **Коммит только после тестирования**
6. **Push в feature/* → PR → main**

## Паттерны работы

### Давать задачу поэтапно

❌ **Плохо:**
```
Сделай весь рефакторинг bookmarklet
```

✅ **Хорошо:**
```
@docs/instructions/WAVE_3.2_PHASE_1_BOOKMARKLET.md
Выполни задачу 1.1: Setup esbuild
```

### Указывать образцы

✅ **Хорошо:**
```
Создай TaskService по образцу из backend/app/services/session_service.py
```

### Проверять промежуточные результаты

✅ **Хорошо:**
```
Покажи что получилось, затем переходим к следующей задаче
```

## Если агент потерял контекст

Признаки:
- Спрашивает про устаревшие вещи (GitHub Issues вместо YouGile)
- Не знает про текущий Wave
- Предлагает неправильную архитектуру

Решение:
```
Прочитай CLAUDE.md и .claude/settings.local.json заново.
Мы работаем над WAVE 3.2, текущая фаза: Phase 1 Bookmarklet.
```

---

## Обновление инструкций

Когда начинается новый Wave или фаза:

1. Обновить `CLAUDE.md` — актуальный статус
2. Обновить `settings.local.json` — текущий wave
3. Создать новые файлы в `docs/instructions/`
4. Обновить `docs/ROADMAP.md`

## Примеры команд

**Начало работы:**
```
Привет, коллега! Продолжаем работу над ErrorLens. 
Что у нас в текущем Wave?
```

**Конкретная задача:**
```
@docs/instructions/WAVE_3.2_PHASE_2_BACKEND.md
Создай ArticleService по образцу из session_service.py
```

**Проверка статуса:**
```
Покажи статус WAVE 3.2 — какие фазы готовы, какие в работе?
```

**Commit и push:**
```
Закоммить изменения с сообщением "[Wave 3.2] Phase 1 complete"
и создай PR
```
