ErrorLens

AI-powered error analysis for QA engineers

Debug faster with AI

A lightweight bookmarklet that captures browser errors and sends them to AI for instant analysis. No registration, no extensions, works everywhere.

Features

  • Captures console errors, warnings, and logs
  • Records failed network requests (4xx, 5xx)
  • Catches unhandled JavaScript exceptions
  • AI analysis with probable cause and fix suggestions
  • Export to Markdown for Jira/GitHub issues
