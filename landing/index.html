ErrorLens

AI-анализ ошибок для QA-инженеров

Dashboard

Отлаживайте быстрее с AI

Легковесный букмарклет, который захватывает ошибки браузера и отправляет их на AI-анализ. Без регистрации, без расширений, работает везде.

Установка

Нажмите кнопку, чтобы скопировать код букмарклета:

После копирования:

  1. Нажмите Ctrl+Shift+B чтобы показать панель закладок
  2. Правый клик на панели закладок → "Добавить страницу..."
  3. Имя: ErrorLens
  4. URL: вставьте скопированный код (Ctrl+V)
  5. Сохраните
Как использовать
  1. Откройте страницу, которую хотите протестировать
  2. Нажмите на закладку ErrorLens
  3. Появится виджет записи — нажмите для старта
  4. Воспроизведите баг
  5. Нажмите "Стоп" для получения AI-анализа

Возможности

  • Захват console.log, warn, error
  • Запись неудачных сетевых запросов (4xx, 5xx)
  • Перехват необработанных JavaScript исключений
  • AI-анализ с указанием причины и способа исправления
  • Экспорт в Markdown для Jira/GitHub
  • Генерация Postman-коллекций из записанных запросов
