ErrorLens

AI-анализ ошибок для QA-инженеров

Отлаживайте быстрее с AI

Легковесный букмарклет, который захватывает ошибки браузера и отправляет их на AI-анализ. Без регистрации, без расширений, работает везде.

Установка

Перетащите эту кнопку в панель закладок:

ErrorLens

Как использовать:

  1. Перетащите кнопку выше в панель закладок
  2. Откройте страницу, которую хотите протестировать
  3. Нажмите на закладку ErrorLens
  4. Появится виджет записи — нажмите для старта
  5. Воспроизведите баг
  6. Нажмите "Стоп" для получения AI-анализа

Возможности

  • Захват console.log, warn, error
  • Запись неудачных сетевых запросов (4xx, 5xx)
  • Перехват необработанных JavaScript исключений
  • AI-анализ с указанием причины и способа исправления
  • Экспорт в Markdown для Jira/GitHub
  • Генерация Postman-коллекций из записанных запросов
